# Dix pistes d’outils locaux — 28 octobre 2026

Propositions à choisir ensemble, pas une liste de fonctions déjà développées. Les adaptations ci-dessous sont nos propositions ; les liens décrivent les logiciels qui les inspirent. Objectif : traitement sur le PC, outils accessibles à la demande dans l’interface actuelle, sans ajouter dix boutons permanents.

| Choix | Outil proposé | Inspiration et plateforme | Apport dans NextExplorer | État et effort estimé |
| --- | --- | --- | --- | --- |
| [ ] | Comparer le contenu de deux fichiers | [KDiff3](https://apps.kde.org/kdiff3/) — Linux, macOS, Windows | Sélectionner un fichier par panneau et voir les lignes ajoutées/supprimées ; fusion manuelle dans une copie ensuite. | Notre comparaison distante porte sur noms/tailles/dates. Première version texte en lecture seule : moyen ; fusion : important. |
| [ ] | Synchroniser deux dossiers | [Synchronizer de Krusader](https://docs.kde.org/trunk_kf6/en/krusader/krusader/synchronizer.html) — Linux | Comparaison récursive avec exclusions, puis copie des fichiers manquants ou modifiés vers un disque ou un serveur. | Complète les transferts et la comparaison du niveau affiché. Important : conflits, fichiers modifiés pendant l’analyse et reprise ; commencer en copie unidirectionnelle sans suppression. |
| [ ] | Expliquer pourquoi un fichier est verrouillé | [File Locksmith, PowerToys](https://learn.microsoft.com/windows/powertoys/file-locksmith) — Windows | Sur un échec de déplacement ou suppression, montrer l’application qui utilise le fichier. | Absent. Moyen à important côté Windows ; diagnostic d’abord, aucune fermeture forcée automatique. |
| [ ] | Extraire le texte des images et scans | [Text Extractor, PowerToys](https://learn.microsoft.com/en-us/windows/powertoys/text-extractor) — Windows | Copier le texte de l’image sélectionnée ; ensuite indexer les scans pour la recherche locale. | Aucun OCR actuellement. Moyen pour une image, important pour PDF multipages/indexation. Moteur et langues locaux à qualifier. |
| [ ] | Coller le presse-papiers comme fichier | [Advanced Paste, PowerToys](https://learn.microsoft.com/en-us/windows/powertoys/advanced-paste) — Windows | Ctrl+V dans le dossier : capture copiée → PNG, texte copié → TXT/Markdown, avec nom modifiable et sans écrasement. | La collecte web et le copier/coller de fichiers existent, pas ce parcours général. Faible à moyen ; permissions du presse-papiers à vérifier. Actions classiques locales uniquement. |
| [ ] | Inspecter un fichier inconnu en hexadécimal | [Okteta](https://apps.kde.org/okteta/) — Linux | Onglet d’aperçu « Octets » montrant signature, décalage, valeurs hexadécimales et caractères, avec lecture par pages. | Absent. Moyen ; lecture seule pour commencer, aucun chargement intégral de gros fichiers. |
| [ ] | Chiffrer ou signer un fichier indépendant | [Kleopatra](https://apps.kde.org/kleopatra/) — Linux et Windows | Créer une copie chiffrée, vérifier une signature reçue, ou signer un livrable localement. | Le chiffrement d’archives existe ; pas ce parcours de signatures/clés. Important : moteur, gestion des clés, sauvegarde et récupération à concevoir. |
| [ ] | Construire des recettes d’actions | [Raccourcis et actions rapides](https://support.apple.com/en-au/guide/shortcuts-mac/apd163eb9f95/mac) — macOS | « Redimensionner → renommer → ZIP → copier vers mon dossier de livraison » dans une recette réutilisable. | Conversion puis ZIP et rangement par règles existent déjà. Moyen à important pour les combiner ; commencer par les actions internes, sans scripts téléchargés. |
| [ ] | Voir les changements Git dans l’explorateur | [Kommit](https://apps.kde.org/kommit/) — Linux | Badges de fichiers modifiés, diff et historique depuis le dossier de projet, sans quitter la navigation. | La commande Git status existe déjà. Moyen pour un enrichissement en lecture seule ; staging/commit à décider séparément. Git installé requis. |
| [ ] | Remplir les formulaires PDF | [Aperçu : formulaires et signature](https://support.apple.com/guide/preview/fill-out-and-sign-pdf-forms-prvw35725/mac) — macOS | Renseigner les vrais champs d’un formulaire dans l’aperçu puis enregistrer une copie ; signature dessinée éventuellement réutilisable. | L’annotation et la création PDF existent déjà, pas l’édition des champs. Moyen à important ; une signature dessinée n’est pas une signature cryptographique. |

Priorité suggérée : **comparaison texte**, **coller comme fichier**, puis **diagnostic des verrous**. Elles complètent les usages existants avec peu de contrôles visibles. La synchronisation et les recettes viennent ensuite, une fois leurs règles de sécurité et d’annulation définies. Ces estimations portent sur le périmètre proposé, pas sur l’intégration du logiciel cité ni sur la reprise de son code.

## Ajouts demandés dans la même session

- [x] Aperçu des polices TTF, OTF, WOFF et WOFF2 dans le volet et la fenêtre d’aperçu : échantillon personnel et taille 12–96 px, sans installation système, fichier limité à 16 Mio et chargement borné. Les collections TTC/OTC et la liste exhaustive des glyphes restent hors périmètre.
- [x] Bouton Modifier directement dans l’aperçu texte : éditeur existant réutilisé sans modale, recherche et coloration, Ctrl+S, version précédente et refus en cas de modification externe. UTF-8, 128 Kio ; brouillons conservés en mémoire pendant les changements de sélection/outils, avertissement à la fermeture de la page. Aucun enregistrement automatique.

Voir [le guide des documents et aperçus](FEATURES_DOCUMENTS_LOCAUX.md) pour les limites et la validation.
