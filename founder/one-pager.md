# NextExplorer — note de décision en deux minutes

**Décision proposée : continuer le pilote gratuit, différer la vente Pro. Verdict calculé : Incomplete.**

Problème à valider : préparer les bons documents/images pour une page web impose des changements de contexte et des opérations répétées. Cible de travail : utilisateurs réguliers Windows/Chrome, notamment indépendants ; segment non confirmé par enquête.

Offre actuelle : exploration/préparation locale gratuite, extension et compagnon Windows ; installation manuelle et EXE non signé annoncés. Offre Pro envisagée : classement assisté/recherche par sens locaux, prix candidat 49 € une fois ; non livrée, non vendue, gratuit conservé.

| Signal | Résultat et portée |
| --- | --- |
| Technique | Pilote public 1.0.7 et recettes documentées ; pas une preuve commerciale |
| Board | Trois FUND IF, moyenne qualitative 4,67/10 |
| Simulation du concept Pro | 0/20 intentions, puis 0/20 après clarification ; pas une prévision |
| Concurrence | Huit alternatives relevées ; IA locale déjà présente, avantage web à démontrer |
| Finances réelles | Inconnues, dossier Incomplete |
| Scénario central seulement | 28,125 € de contribution/licence ; 29,87 nouvelles licences/mois pour équilibre ; −2 345,62 €/an à 275 licences |

Besoin immédiat : temps d'observation et données de coûts, **aucune somme à lever chiffrée**. Première expérience : cinq volontaires sur une tâche identique, temps/erreurs face à leur parcours actuel, installation et aide consignées, retour d'usage à deux semaines. Ne pas prendre leurs fichiers privés par défaut.

Demande au propriétaire : choisir le parcours prioritaire, confirmer temps/budget, faire observer les volontaires. Dépenses, nouveau nom et paiement restent des décisions ultérieures. Les scénarios et profils sont synthétiques ; le réel les remplace dès qu'il existe.
