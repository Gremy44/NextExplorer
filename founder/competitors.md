# Concurrence — relevé du 11 novembre 2026

Étude documentaire, sans essai comparatif des applications. Huit alternatives dans [le CSV](competitors.csv). Les affirmations ci-dessous reprennent les pages officielles consultées ; absence de fonction dans une page ne prouve pas son absence dans le logiciel.

| Alternative | Proposition constatée | Pression sur NextExplorer |
| --- | --- | --- |
| [Files](https://files.community/) | Onglets, tags et double panneau ; open source, achat Store soutenant le projet | Un explorateur moderne et riche n'est pas un positionnement suffisant |
| [Directory Opus](https://www.gpsoft.com.au/) | Personnalisation, transferts, tags, images ; licence perpétuelle, prix dynamique non extrait | Rival fonctionnel mature ; éviter la course à la parité |
| [XYplorer](https://www.xyplorer.com/purchase.php) | 34,95 USD standard avec un an de mises à jour, 69,95 USD lifetime | Achat unique d'utilitaire plausible ; aucune preuve que notre cible paiera 49 € |
| [File Pilot](https://filepilot.tech/pricing) | Bêta gratuite et licences perpétuelles ; prix numériques non visibles dans l'extraction | Vitesse et simplicité constituent un axe concurrentiel |
| [TagSpaces Lite](https://www.tagspaces.org/products/lite/) et [Pro](https://www.tagspaces.org/products/pro/) | Tags/aperçus hors ligne ; chat Ollama en Lite, fonctions IA locales en Pro | **L'IA locale ne sera pas une exclusivité de NextExplorer** |
| [Everything](https://www.voidtools.com/) | Recherche rapide par nom annoncée | Ne pas vendre la simple recherche comme innovation |
| [Organize](https://github.com/tfeldmann/organize) | Automatisation de fichiers par règles | Le classement classique a des substituts disponibles |
| [PowerToys](https://learn.microsoft.com/en-us/windows/powertoys/) | Outils Windows gratuits et open source | L'assemblage de fonctions connues ne suffit pas à créer une prime de prix |

Substitut principal à observer : Explorateur Windows + dialogue d'envoi du navigateur + utilitaires déjà installés. Le coût du changement et l'habitude comptent autant que le prix du logiciel. Cette conclusion est une inférence de produit, pas un résultat d'enquête.

## Prix et comparabilité

Pas de médiane valable : un seul couple de tarifs payants a été extrait de façon explicite, en USD ; les offres n'ont pas le même périmètre. Files a un prix régional Store, Directory Opus et File Pilot des montants dynamiques non rendus ; TagSpaces Pro n'a pas été chiffré dans les pages lues. Ne pas compléter depuis des blogs ou convertir arbitrairement les devises. Le gratuit met une pression réelle sur une proposition à 49 €, sans déterminer un prix acceptable.

## Retours publics : preuve encore mince

Le [suivi TagSpaces](https://github.com/tagspaces/tagspaces/issues) affiche notamment « Sidecar file tags not searching » ; [un sujet de forum](https://tagspaces.discourse.group/t/search-by-tags-not-showing-all-results/344) porte sur des résultats de tags incomplets. Ce sont des signalements, pas une fréquence ni l'état de la version actuelle. Thème exploratoire : confiance dans l'exhaustivité de la recherche. Moins de trois retours analysés : **preuve mince**, aucune généralisation.

La recherche filtrée d'issues Files n'a pas été accessible dans l'outil. Aucun corpus comparable d'avis clients, note moyenne ou taux de plainte n'a été validé pour les autres produits. Il reste à lire un échantillon daté avant d'affirmer que leurs utilisateurs sont insatisfaits. On ne dispose pas d'un « manque du marché » prouvé.

## Carte et angle à tester

Axes qualitatifs : exploration généraliste ↔ préparation d'une tâche web ; application autonome ↔ contexte navigateur. Files/Opus/XYplorer/File Pilot représentent l'exploration autonome ; Organize le rangement ; TagSpaces l'organisation documentaire ; notre panneau vise le travail avec une page ouverte. Cette carte est notre interprétation, pas une mesure des produits.

Angle candidat : préparer les fichiers requis puis les déposer sur la page en restant dans son contexte, avec des copies et des limites claires. Le gain à démontrer porte sur le temps et les erreurs de cette tâche ; il ne faut pas dire « personne ne le fait ». Menace : un gestionnaire existant ou une extension peut reproduire une partie du flux. Les scénarios, la fiabilité et une distribution simple doivent devenir l'avantage accumulé.
