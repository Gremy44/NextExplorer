# NextExplorer — nom de travail

État de référence : 11 novembre 2026. Source privée ; préversion gratuite publique 1.0.7-pilot.1. Ces rapports constituent une étude interne, pas des annonces commerciales.

- Produit : explorer, organiser et préparer des fichiers locaux tout en travaillant dans Chrome/Edge, via une extension et un compagnon Windows.
- Public général visé : utilisateurs Windows/Chrome. Premier segment candidat : personnes manipulant régulièrement documents et images pour des tâches web, dont indépendants et projets personnels. Pas de données réelles de segmentation disponibles.
- Aujourd'hui : version gratuite, sans compte NextExplorer, code privé, téléchargements/documents publics ; dons volontaires possibles. Exploration, onglets/double panneau, tags, recherche lexicale, aperçus, édition texte, versions/corbeille, atelier/conversion selon moteurs, console, collecte et glisser-déposer vers sites témoins. Connexions distantes facultatives, qualification externe encore ouverte.
- Demain, hypothèse non implémentée : un pack Pro local pour classement assisté et recherche par sens, documents/images selon qualification. Prix de travail historique : 49 € achat unique, une personne/deux PC, 12 mois d'évolutions, version acquise conservée ; essai candidat de 14 jours après première analyse réussie. Aucun achat actif, prix non validé, régime fiscal non déterminé.
- Distribution actuelle : GitHub, extension chargée manuellement, EXE non signé. Recette Windows isolé Chrome/Edge accomplie ; pilote externe 5–10 personnes encore à documenter. Store envisagé, statut actuel non vérifié.
- Contraintes : projet solo, objectif complément de revenu, traitement local, pas de serveur de fichiers/cloud imposé, gratuit conservé, refus de dépenses de distribution/signature actuellement. Budget d'exploitation et temps hebdomadaire inconnus ; ne pas les assimiler à zéro.
- Nom NextExplorer contesté par homonymie constatée ; aucun droit de marque ni nouveau nom validé.
